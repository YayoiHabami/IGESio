# Fixture Models

This directory contains fixture (jig) models used by the machines extension samples.

| File | Modeled after |
|------|---------------|
| `erowa_er-115308.STL` | EROWA ER-115308 |
| `lang_macro-grip_48120-77_slides=80.STL` | LANG MAKRO-GRIP 48120-77 (jaw slides at 80 mm) |
| `lang_macro-grip_48120-77_slides=100.STL` | LANG MAKRO-GRIP 48120-77 (jaw slides at 100 mm) |
| `lang_round-plate_45901.STL` | LANG round plate 45901 |
